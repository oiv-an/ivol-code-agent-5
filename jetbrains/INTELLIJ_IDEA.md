# IVOL Code Agent 5 для IntelliJ IDEA

> Для разработчика с **IntelliJ IDEA 2025.3.6.1 (IU-253.33813.55)** подготовлен отдельный целевой вариант: [инструкция IDEA 2025.3](INTELLIJ_IDEA_2025_3.md). Пакет для 2026.2, описанный ниже, туда устанавливать нельзя. Результаты 5.16.231 ниже относятся к ранее опубликованной сборке.

Целевая стабильная IDE на 8 сентября 2026 года: **IntelliJ IDEA 2026.2.2**, сборка **IU-262.10315.125**.
Версия общего ядра IVOL: **5.16.234**. Номер версии IDE и номер версии плагина независимы.

Официальные источники: [релиз IDEA](https://blog.jetbrains.com/idea/2026/09/intellij-idea-2026-2-2/),
[API стабильных релизов](https://data.services.jetbrains.com/products/releases?code=IIU&latest=true&type=release),
[совместимость плагинов JetBrains](https://plugins.jetbrains.com/docs/intellij/plugin-compatibility.html).

## Требования и границы совместимости

- IntelliJ IDEA 2026.2, ветка платформы 262. Новые основные версии требуют отдельной проверки; диапазон совместимости намеренно не открыт бессрочно.
- Стандартный JetBrains Runtime с Java 25 и JCEF; включённый встроенный плагин Terminal.
- Установленный Node.js не ниже 20.6.0, доступный IDE. Исполняемый файл Node.js в ZIP не включён.
- В пакет включены нативные зависимости для macOS Apple Silicon и Intel, Windows x64 и Linux x64.
- Windows ARM64 и Linux ARM64 этой сборкой не заявлены. Наличие нескольких вариантов нативных файлов не заменяет проверку запуска на каждой системе.

## Установка из файла

Готовый ZIP: [скачать из GitHub Release 5.16.234](https://github.com/oiv-an/ivol-code-agent-5/releases/download/v5.16.234/ivol-code-agent-5-5.16.234-intellij-idea.zip).

1. В IntelliJ IDEA откройте Settings → Plugins → меню с шестерёнкой → Install Plugin from Disk.
2. Выберите скачанный `ivol-code-agent-5-5.16.234-intellij-idea.zip` без распаковки. После локальной сборки его копия также находится в `bin` в корне репозитория.
3. Перезапустите IDEA, когда закончите текущую работу. Плагин появится в боковой панели **IVOL Code**.

Официальный Kilo Code нельзя включать одновременно с этим форком в одной IDE.
Обновление выполняется поверх существующего IVOL, без удаления истории или настроек.
[Инструкция JetBrains по установке из ZIP](https://www.jetbrains.com/help/idea/managing-plugins.html#install_plugin_from_disk).

В 5.16.234 исправлена ошибка сохранения истории на Windows (`EPERM: fsync`, `API conversation history could not be saved`). Общая правка включена во все редакции. Исправление параллельного запуска нативных библиотек из 5.16.233 сохранено. Удалять пользовательские данные для обновления не нужно.

## Данные

Идентификатор плагина остаётся `pro.ivol.kilocode5.jetbrains`, внутренний идентификатор расширения — `Kilo Code.kilo-code`.
Пути данных не переименовываются: JetBrains-версия использует `~/.kilocode/globalStorage` и `~/.kilocode/workspaceStorage`.
На одном компьютере IDEA и PhpStorm используют общие каталоги данных JetBrains-версии; это не новая изолированная копия истории.
Настройки IDE автоматически из PhpStorm в IDEA не переносятся. Сборка и проверка плагина сами по себе не изменяют эти данные.

## Воспроизводимая сборка

Запускайте из `jetbrains/plugin`, имея Java 25, подготовленный `plugins/kilocode/extension`
с общим ядром 5.16.234, собранный host и проверенный архив нативных зависимостей `platform.zip`.
Указывайте реальные локальные пути вместо примеров ниже.

```sh
./gradlew verifyBuildTargetConfiguration test buildPlugin verifyPlugin \
  -PplatformType=IU \
  -PplatformVersion=2026.2.2 \
  -PlocalIdePath="/path/to/IntelliJ IDEA.app" \
  -PdebugMode=release \
  -PplatformZipPath="/path/to/platform.zip" \
  --offline --no-daemon --max-workers=2 \
  -Pkotlin.compiler.execution.strategy=in-process
```

`localIdePath` должен указывать именно на IDEA ветки 262, не на PhpStorm.
Если локального SDK нет, уберите `localIdePath` и `--offline`: Gradle получит выбранную версию IDEA как зависимость сборки.
Это не устанавливает плагин в пользовательскую IDE и не запускает её.

IDEA использует отдельный каталог `build/idea` и суффикс `-idea.zip`.
Обычная сборка PhpStorm по умолчанию остаётся в `build/distributions`; готовые архивы не перезаписываются друг другом.
Проверка совместимости использует тот же SDK, против которого компилируется плагин.
Учтите: обычный `clean` удаляет весь `build`, включая вложенный `build/idea`.
Поэтому проверенный установочный ZIP для передачи пользователю дополнительно сохраняется в корневом `bin`, вне каталога сборки.

Тесты и Plugin Verifier проверяют код и совместимость API. Интерактивный запуск, терминал и JCEF в реальном окне IDEA проверяются отдельно после установки пользователем.

## Проверка 5.16.234

Проверки для IU-262.10315.125 включают автоматические тесты, Plugin Verifier и сравнение общего ядра, интерфейса и host с остальными пакетами 5.16.234. Результаты и контрольные суммы записываются в локальный `.verification.json` рядом с ZIP. Интерактивный запуск и другие ОС проверяются отдельно после установки; автоматическая проверка API их не заменяет.
