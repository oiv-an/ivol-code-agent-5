# Завершённая задача остаётся открытой

Исправление тестовой сборки VS Code 5.16.237. Она также включает ручное интеллектуальное сжатие из 5.16.236.

Результат завершённой задачи и переписка должны оставаться видимыми. Общее подтверждение через команду расширения или горячую клавишу не означает «Новая задача» и не должно отправлять `clearTask`. Если после завершения введён текст, команда отправки передаёт его как продолжение той же задачи.

Новая задача по-прежнему создаётся явным нажатием соответствующей кнопки. Крестик закрытия задачи сохраняет своё назначение. Завершение делегированной подзадачи по-прежнему возвращает управление родителю — это отдельный сценарий, не возврат на пустой главный экран.

В коде не обнаружено удаления активной корневой задачи непосредственно обработчиком события `TaskCompleted`. Выявлен путь закрытия через общий обработчик основной кнопки: после завершения он использовался и для явной навигации, и для общего подтверждения. Проверки различают эти действия.

Изменение находится в общем интерфейсе расширения. В версии 5.16.240 оно включено также в сборки PhpStorm, IntelliJ IDEA и PyCharm. Подготовка сборок не меняет установленные плагины или историю задач.
