# Проверка провайдера — все поддерживаемые IDE

Добавлена в VS Code 5.16.239; в версии 5.16.240 включена также в сборки PhpStorm, IntelliJ IDEA и PyCharm.

В настройках провайдера заполните адрес, ключ и модель, затем нажмите **«Проверить»**.
Проверка использует текущие значения формы, включая пользовательские заголовки и настройку TLS.
Сохранять профиль перед проверкой не требуется. Результат сбрасывается при изменении полей или профиля.

Плагин отправляет короткий запрос выбранной модели: `Reply with IVOL_CONNECTION_OK only.`
Это настоящая генерация, оплачиваемая по обычным правилам провайдера. История задачи, код проекта,
инструменты и веб-поиск в запрос не включаются. Проверка не создаёт задачу и не сохраняет профиль.
Подписочные провайдеры используют существующий вход; обычное обновление OAuth-токенов при этом возможно.

Поддержаны OpenAI Compatible, ChatGPT/Codex, Claude Code, Ollama и LM Studio.
OpenAI Compatible проверяется через обычный Chat Completions; подписка ChatGPT использует свой адаптер.
Веб-поиск через Responses проверяется отдельно, не этой кнопкой.

После проверки нажмите **«Скопировать отчёт»** и отправьте его в поддержку.
В отчёте указаны версия расширения, среда, провайдер, модель, безопасно сокращённый адрес,
длительность, результат и доступные HTTP/сетевые коды и идентификатор запроса.
Если адаптер не передал HTTP-статус, он отмечается как недоступный, а не подменяется вымышленным `200`.
Ключи, значения заголовков, содержимое ответа, история, необработанные ошибки и стеки не включаются.
Для неизвестной ошибки выводится безопасное общее описание: по такому отчёту иногда потребуется
дополнительная проверка серверного журнала по времени и идентификатору запроса.

Успех подтверждает получение непустого текста в этом коротком запросе. Он не гарантирует работу
длинных задач, инструментов, сжатия контекста или веб-поиска. Проверка не определяет, включён ли VPN.
При неограниченно длинном ответе чтение останавливается на локальном пределе 8 КиБ с явной отметкой.
Ожидание ограничено 60 секундами. Можно нажать «Отмена»; смена профиля или закрытие панели также
отменяет проверку. Отмена соединения не гарантирует, что сервер прекратит уже начатые вычисления.

Поддерживаемые IDE получают общее ядро и интерфейс проверки. Установленные IDE и их данные при подготовке
сборок не изменяются. Экспериментальная «Интеллектуальная задача» остаётся выключенной по умолчанию;
предыдущие локальные исправления сохранены. Интерфейс новой проверки переведён на русский и английский.
