# Contributing to IVOL Code Agent 5

IVOL Code Agent 5 is a stability-focused fork of the upstream v5.16.2 codebase. Bug reports and narrowly scoped fixes are welcome in the [GitHub issue tracker](https://github.com/oiv-an/ivol-code-agent-5/issues).

Before opening an issue, remove API keys, provider credentials, task history, private source code, and other sensitive information from screenshots and diagnostic files.

For local development, follow [DEVELOPMENT.md](DEVELOPMENT.md). Please keep pull requests focused, explain the user-facing behavior being changed, and include relevant tests.

The original upstream project is available at [Kilo-Org/kilocode-legacy](https://github.com/Kilo-Org/kilocode-legacy). Upstream support channels are not support channels for this independent fork.
